# Changelog
Bu dosya Qwen Code Türkçe projesinde yapılan önemli değişiklikleri sürüm bazında takip etmek için kullanılır.
Bu proje bağımsız bir Türkçe topluluk dokümantasyonu çalışmasıdır.

- OpenAI uyumlu API rehberi

- Agent ve Subagent rehberi
- Qwen Code hata çözme rehberi
- Windows ipuçları

- CONTRIBUTING.md
- SECURITY.md
- Apache License 2.0
### Proje Hedefi
Qwen Code için Türkçe konuşan geliştiricilerin kullanabileceği güncel, uygulanabilir ve sürdürülebilir bir topluluk dokümantasyonu oluşturmak.
### Sonraki Hedefler
- Gerçek kullanım örnekleri eklemek
- Yeni Qwen Code sürümlerini takip etmek
- MCP örneklerini genişletmek
- Yerel model testleri eklemek
- Linux ve macOS rehberleri hazırlamak
- Topluluk issue ve pull request katkılarını değerlendirmek
## Sürüm Politikası
Yeni önemli dokümantasyon bölümleri, büyük güncellemeler ve kapsamlı düzeltmeler yeni sürümlerde bu dosyada kaydedilecektir.
