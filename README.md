# Qwen Code Türkçe

Qwen Code için bağımsız Türkçe topluluk dokümantasyonu, kurulum rehberleri, kullanım örnekleri ve sorun giderme kaynakları.

Bu proje Qwen ekibinin resmi projesi değildir. Türkçe konuşan kullanıcıların Qwen Code'u daha kolay kurabilmesi, yapılandırabilmesi ve kullanabilmesi amacıyla hazırlanmış bağımsız bir topluluk çalışmasıdır.

## Qwen Code Nedir?

Qwen Code, yazılım geliştirme görevlerinde yapay zeka modellerinden yararlanmayı sağlayan açık kaynak coding agent projelerinden biridir.

Bir proje üzerinde:

- kod analizi
- dosya inceleme
- kod üretme
- hata çözme
- refactoring
- test oluşturma
- terminal araçları
- agent tabanlı geliştirme

gibi görevlerde kullanılabilir.

Gerçek özellikler kullanılan Qwen Code sürümüne, modele, provider'a ve yapılandırmaya bağlıdır.
